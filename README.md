# SELLERS PLACE — Telegram Mini App

Мини-приложение для канала [@sellersplace2](https://t.me/sellersplace2): площадка для перепродажи брендовой одежды (люкс и премиум).

## Что умеет

**Для продавцов**
- Форма «Продаю» в формате постов канала: бренд | модель, состояние /10, размер, цена, торг, обмен, личная встреча (город), доставка, Garant 3%, описание, 2–10 фото (сжимаются на телефоне).
- Предпросмотр: как пост будет выглядеть в канале.
- После модерации бот сам публикует пост в канал альбомом и присылает автору ссылку.
- «Мои объявления»: статусы (на модерации / опубликовано / отклонено с причиной), кнопка «Продано» дописывает в пост «❌ ПРОДАНО», «Снять» удаляет пост из канала.

**Для покупателей**
- Каталог с поиском, категориями, фильтрами (размер, город, цена) и сортировкой.
- Карточка вещи: галерея, характеристики, «Написать продавцу», «Сделка через гаранта», избранное, поделиться, ссылка на пост в канале.
- Раздел «Ищут» — запросы покупателей (#поиск), продавцы пишут напрямую.

**Оплата размещения (150 ₽ за вещь, у администратора в личных сообщениях)**
1. Продавец заполняет объявление → оно получает номер (#123) и статус «Ждёт оплаты».
2. Кнопка «Написать администратору» открывает его ЛС с готовым сообщением:
   «Хочу оплатить размещение объявления #123 — Stone Island Oleander sweatshirt (150 ₽)». Та же кнопка приходит продавцу в бота.
3. Админам в бота сразу приходит объявление с номером #123 и кнопками «✅ Оплачено — опубликовать» / «❌ Отклонить».
   Админ принимает оплату в ЛС, находит объявление по номеру и нажимает «Оплачено» — пост уходит в канал.
4. «Оплата не поступила» оставляет объявление в ожидании и шлёт продавцу напоминание.

Админы публикуют без оплаты. Цена и контакт задаются в `.env` (`POST_PRICE`, `PAYMENT_CONTACT`); `POST_PRICE=0` выключает оплату.

**Для админов**
- Модерация прямо в боте (кнопки «Опубликовать» / «Отклонить» с готовыми причинами) или во вкладке «Модерация» в приложении.
- Хэштеги в постах для навигации по каналу: `#продажа #обувь #RickOwens`.

## Стек

Node.js 22 (встроенный SQLite), Express, grammY. Фронтенд — чистый HTML/CSS/JS без сборки, подстраивается под тему Telegram.

```
server/   index.js (API), bot.js (бот, публикация, модерация), format.js (текст поста),
          auth.js (проверка initData), db.js, catalog.js (категории, бренды), config.js
public/   index.html, app.css, app.js — сам мини-апп
```

## Локальный запуск

```bash
npm install
npm run dev      # http://localhost:3000, без Telegram: тестовый пользователь с правами админа
```

## Запуск в продакшене

1. В @BotFather: `/newbot` → получить токен. Затем `/newapp` (или Bot Settings → Menu Button) и указать HTTPS-адрес приложения.
2. Добавить бота в канал администратором с правами «Публикация», «Редактирование» и «Удаление сообщений».
3. Скопировать `.env.example` в `.env` и заполнить (`BOT_TOKEN`, `WEBAPP_URL`, `ADMIN_IDS`).
4. Развернуть на сервере с HTTPS (VPS + nginx/Caddy, Railway, Render, Fly.io):
   ```bash
   docker build -t sellers-place .
   docker run -d --env-file .env -p 3000:3000 -v sellers-data:/data sellers-place
   ```
   или `npm ci && npm start` (Node ≥ 22.5). Папку `DATA_DIR` (база и фото) нужно сохранять между перезапусками.
5. Закрепить в канале пост с кнопкой-ссылкой на приложение: `https://t.me/<бот>/<app>`; на конкретную вещь — `?startapp=item_<id>`, сразу на форму продажи — `?startapp=sell`.
